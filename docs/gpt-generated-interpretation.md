# GPT 직접 해석 작성 전환

2026-11-17 사용자 요청은 모델 추천·설정이며, 추가 답변으로 모델 교체와 직접 해석 작성을 함께 승인했다. 기존 서버 문장 ID 선택 방식은 새 보고서에서 사용하지 않는다.

## 모델 선택

GPT-6.1 Sol / reasoning.effort=low를 선택한다. 여러 공공 지표의 비교·범위·시점 차이를 연결하는 해석을 중시한 판단이다. GPT-6.1 Terra는 제공 자료 기반 간결한 글 작성에 적합한 대안이고, Sol은 복잡한 전문 작업을 위한 후보다. 실제 업무 품질의 절대 우열을 측정한 것은 아니다.

공식 근거: [모델 선택 가이드](https://developers.openai.com/api/docs/guides/model-selection), [GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol), [GPT-6.1 Terra](https://developers.openai.com/api/docs/models/gpt-6.1-terra). Sol의 현재 표준 요금은 입력100만 토큰당$2/출력$10이며 실제 비용은 요청·응답 길이와 캐시에 따른다. low는 응답 지연을 줄이기 위한 시작점이다.

## 생성·검증

- 기존 같은 RR 재조회/baseline 대조 후 지표의 값·표시값·단위·기간·공간·대상·필터·분모와 한계를 모델에 전달한다. UI 전용 행정동 이름·주소·좌표·서명 context·건물 식별자는 전달하지 않는다.
- 역할별 구조화 JSON의 items(text/evidence_ids/group_id)를 직접 작성한다. 이점·유의점은 최대3개, 요약은 자료 그룹마다 정확히 한 문단이다. 준비 문장/후보 ID 선택은 없다.
- ID·타입·길이·중복 키·그룹 누락/혼합·수치·단위를 검증한다. 표시값 외 새 계산/배수/환산은 허용하지 않는다. 원자료 라벨의 최근12개월 등 기간 표현은 허용하되 값의 단위 변경, 근거 없는0, 음수/퍼센트포인트 변조는 거절한다. URL/HTML/일부 보장·추천 표현도 거절한다.
- 검사는 수치와 근거 연결 구조를 확인하는 것으로, 자유 문장의 모든 의미·인과관계가 참이라는 증명은 아니다. 프롬프트에서 성공/미래매출/수익 예측·고객 전환 추정·투자/계약 권고를 금지하고 필수 한계 안내를 별도로 유지한다.
- 실패 역할은 verification_failed/unavailable로 처리한다. 자동 재작성/검증 재시도는 없으며 정상 신규3호출, 캐시/PDF0호출을 유지한다.
- 완전 성공한 검증 문장만 메모리 캐시에 저장하고 HIT에도 현재 근거로 재검증한다. prompt/model/reasoning/근거 판본·기준 토큰을 캐시 키에 반영한다. FE 캐시 prefix도 v2로 바꿔 과거 선택형 결과와 구분한다.
- 응답의 기존 ai-sections-v1 구조와 plain text 렌더링을 유지한다. 수치·출처 카드 제거와 체크리스트도 유지한다. schema_version은 응답 형태이고 생성 방식은 meta.interpretation_method=model_authored_evidence_checked_v2다.

## 시간·실제 검증

간단한 직접 해석 probe는 Sol200/2.92초였다. 실제 공공 지표로 이점3·유의점3·요약6문단을 작성한 별도3역할 검증은6.59/12.41/10.36초이며 모두200/수치·근거 검사 통과다. 기존12초를 초과한 경우가 있어 공급자/역할15초, 준비35초, 전체70초, FE90초로 맞췄다. 토큰 상한4096은 추론과 문장 출력을 함께 고려한다. 이 수치는 한 사례이며 운영 지연을 보장하지 않는다.

첫 실 운영 요청은36.50초200 partial이며 이점·요약은ready, 유의점은15초 timeout이었다. 이에 공급자/역할20초, 준비35초, 전체80초, FE90초로 보완한다. 실제 완료 여부는 후속 운영 재검증으로 확인하며 자동 재시도를 추가하지 않는다.

Codex 정적 검토 및 회귀74건(OpenAI/기존 전송/직접 문장 검증), ruff/mypy130파일, FE 회귀1건/lint/production v2 빌드를 확인했다. 실 운영 전체 요청과 캐시·브라우저 결과는 배포 PR에 추가 기록한다.

서버 LLM_MODEL/LLM_REASONING_EFFORT만 변경하고 기존 키·서명 키·DB·기타 환경값은 보존한다. 키 원문은 파일·문서·로그·FE에 저장하지 않는다. BE 선배포 후 FE를 공개한다.
