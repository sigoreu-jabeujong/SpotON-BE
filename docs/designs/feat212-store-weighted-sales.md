# 점포 수 가중 매출 추정 분포·중앙값 (#212)

2026-11-17 최신 사용자 요청은 총점포 수(예:673개)를 반영한 분포 그래프와 그 중앙값을 추정매출 대표값으로 쓰는 것이다. 이전의 sᵢ/Σnᵢ 기여 막대는 이 요청에 따라 교체한다. 실제 적용 수는 요청 위치/같은 분기 유효 자료의 Σnᵢ이며673을 하드코딩하지 않는다.

## 추정 모델과 한계

원자료는 상권·업종별 총매출sᵢ와 점포 수nᵢ다. 개별 점포 매출이나 상권 내부 분산이 없으므로 실제673개 점포의 매출 분포/중앙값을 복원할 수 없다. 대신 xᵢ=sᵢ/nᵢ에 가중치nᵢ를 준 추정 분포를 만든다. 이는 해당 상권 평균이 nᵢ개 점포에 적용된다는 모델이다. 전체 점포 수를 가중치로 반영하는 사용자 의도를 구현하되 화면과 API에 모델 기반임과 개별 실매출 관측 아님을 명시한다. 기존 중첩/미중복제거 메타는 유지하며 고유673개 점포라는 보증은 하지 않는다.

정렬한 xᵢ의 누적 점포 수로 중앙 순위를 찾는다. N이 홀수면 (N+1)/2번째, 짝수면 N/2와 N/2+1번째의 평균을 Fraction으로 구한다. 예를 들어 n=[500,100,73], x=[100,200,1000]의 N=673 가중 중앙값은100이며, 행을 같은 비중으로 본 중앙값200 및 가중평균143000/673과 다르다. 수백만·수천억개의 행을 복제하지 않고 최대500개 원자료만 처리한다.

히스토그램은 정확한 Fraction min~max를 min(10,고유 x 수)개의 같은 폭으로 나눈다. [lower,upper), 마지막만 upper 포함. 각 막대 높이는 해당 구간의 Σnᵢ이며 모든 높이 합은 N이다. 모든 x가 같으면 폭0 단일 구간에 N을 둔다. 실제0은 포함하고 결측·0점포/매핑충돌 제외는 기존 규칙을 유지한다. 다른 분기는 독립 계산한다.

분산은 Σnᵢ(xᵢ−S/N)²/N의 **상권 평균 간** 모델 가중 분산(Decimal50 근사)이다. 상권 내부 개별 점포 분산/전체 실매출 분산은 아니다. 정규분포 곡선·임계값 선택·이상치 제거·가상의 개별 매출 편차를 만들지 않는다.

## API·FE

`representative_method=store_weighted_median_v1`, `graph_basis=store_weighted_histogram_v1`. 대표 및 각 분기 그룹의 `store_weighted_distribution`에는 모델명, `individual_store_sales_observed=false`, N, reference_count, median/mean/minimum/maximum, 범위/가중치 bins, variance와 scope를 넣는다. DTO는 실제 포함 항목에서 전체 모델/히스토그램/중앙값을 재계산하고 대표 투영을 검증한다. 기존 pooled metric/기여목록/동일비중 distribution은 이전 계약 호환용으로 보존한다. 새 FE 대표·차트는 새 필드를 사용한다.

FE 제목은 점포당 추정 매출, 대표는 가중 중앙값. 히스토그램 가로축은 상권별 점포당 추정 매출, 세로축은 원천 점포 수 가중치다. 막대 가중치 합/원자료 n 합/N, 자료행 수와 단위/구간 연속성/범위를 확인한다. 중앙값을 다시 계산하지 않고 서버값으로 점선을 표시한다. Number는 좌표/표시 전제 검사용으로만 사용하고 라벨은 서버 문자열을 유지한다. 단일값·실제0·빈 구간과 결측을 구분한다. 모델 안내·상하가 아닌 좌우/Home/End 구간 선택·360/390px·인쇄 분산을 확인한다. 생활인구 및 기존 제거 문구는 유지한다.

**확인됨 (의미·모델 정직성)**
- 모델: xᵢ=sᵢ/nᵢ를 가중치 nᵢ로 반복하는 모델만 구현했고, 정규분포·상권 내부 편차·가상 개별 매출을 만들지 않는다. `model=repeat_market_mean_for_each_reference_store`, `individual_store_sales_observed=False`, 분산 `scope=between_market_per_store_means`가 API에 실린다.
- 가중 중앙값: (Fraction, n) 정렬 후 누적 가중치로 순위를 찾아 행을 펼치지 않는다. 홀수 N은 `N//2+1`=(N+1)/2, 짝수 N은 N/2·N/2+1 평균(Fraction)이다. 673 예제(500·100·73 → 중앙값 100, 평균 143000/673, 막대 600/0/73)를 손으로 계산해 보니 시험 기대값과 일치한다. 확장 모델 대조 시험(짝수 경계 포함)과 역순 입력 결정성 시험도 의미상 맞다.
- 히스토그램: 정확한 Fraction 같은 폭, 구간 수 min(10, 고유값 수), 경계값은 위 구간으로 가고 최댓값은 마지막(상한 포함) 구간에 들어간다. 마지막 upper=min+width·k=max가 정확히 성립하고, 모두 같은 값이면 width=0 단일 구간이라 0 나눗셈이 없다. 막대 합=N이다.
- 분산: Σnᵢ(xᵢ−S/N)²/N을 prec50 Decimal로 근사하며 단위·범위 표기가 정직하다. 800/9 시험 기대값도 맞다.
- 0·결측·범위: 실제 0 매출(s=0, n>0)은 포함하고, 0점포·매핑충돌·점포행 없음·매출 없음은 기존 규칙대로 제외한다. 입력 범위(s≤2⁶³−1, 0<n≤2³¹−1, bool 거부, 500행 상한)는 기존 `distribution`과 같다. N 최대 약 1.07×10¹²라 FE 안전 정수 범위 안이다.
- DTO: weighted 모드에서는 대표·각 그룹에 필드가 있어야 하고, 실제 포함 항목에서 전체 dict를 재계산해 같아야 하며, 빈 그룹은 None이어야 하고, 대표 투영이 일치해야 한다. 기존 metric·contributions·동일비중 distribution 검증과 구 pooled/구 weighted payload 읽기 호환도 유지된다.
- FE: 대표값은 `representative_method`가 weighted일 때 서버 `median.display`를 쓴다. 차트는 메서드·모델·관측 플래그·N·자료행 수·원천 n 합(BigInt)·단위·구간 연속성(서버 문자열 일치)·범위·막대 합을 검증하고, 실패하면 "분포를 표시할 자료가 없어요"를 보여 준다. 중앙값 점선은 서버값으로 표시하고, "개별 점포 실매출을 관측한 분포는 아니에요" 안내가 화면에 보인다. 좌우/Home/End 이동, 0원 단일 구간(height 100%, left 50%, NaN 없음)도 확인했다. 생활인구·기존 문구는 변경되지 않았다.
